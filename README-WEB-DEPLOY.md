# استقرار وب‌اپ فروهر روی GitHub Pages

1. همهٔ فایل‌های این پروژه را در ریشهٔ مخزن GitHub قرار دهید.
2. در Settings → Pages، گزینهٔ Build and deployment را روی **GitHub Actions** قرار دهید.
3. فایل‌ها را به شاخهٔ `main` یا `master` ارسال کنید، یا از Actions، گردش‌کار **Deploy Faravahar Web App to GitHub Pages** را دستی اجرا کنید.
4. پس از موفقیت، آدرس سایت در بخش Actions و Settings → Pages نمایش داده می‌شود.

## محدودیت مهم
GitHub Pages فقط فایل‌های ایستا را میزبانی می‌کند و `functions/api/*` را اجرا نمی‌کند. بنابراین خود رابط وب منتشر می‌شود، اما API ترجمه و نرخ ارز در این میزبانی فعال نیستند. برای فعال شدن آن‌ها باید APIها را جداگانه روی Cloudflare Pages/Workers مستقر کرد. محتوای خبری فعلی نیز نمونه است و منبع خبر زنده در این پروژه پیکربندی نشده است.
