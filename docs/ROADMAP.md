# نقشه راه تکمیل فروهر

## آماده در نسخه آغازین
- پوسته رابط راست‌چین، واکنش‌گرا و حالت روشن/تاریک
- نشان SVG و نام فروهر
- فهرست و جزئیات خبرهای نمونه
- ذخیره محلی خبرها و تنظیمات
- مسیرهای API نمونه برای ترجمه و نرخ ارز
- PWA پایه

## لازم برای نسخه عملیاتی
1. انتخاب رسانه‌ها و بررسی مجوز/شرایط استفاده از RSS یا API.
2. ساخت Worker زمان‌بندی‌شده (Cron Trigger) برای واکشی منابع، استانداردسازی و حذف تکراری‌ها.
3. محاسبه `publish_at = max(fetched_at, source_published_at + 5 minutes)` و عدم عرضه خبر تا آن زمان.
4. پیاده‌سازی D1 schema و مهاجرت‌ها برای articles, sources, translations, exchange_rates, settings.
5. اتصال API خبری واقعی و نگهداری URL منبع اصلی.
6. انتخاب مدل Workers AI پس از آزمون ترجمه فارسی؛ افزودن cache بر مبنای هش متن و زبان مقصد.
7. انتخاب API نرخ ارز و نوشتن adapter مشخص برای واحد IRR؛ هرگز تبدیل خودکار بر مبنای حدس انجام نشود.
8. افزودن پنل مدیر با احراز هویت واقعی، نقش‌ها و محدودسازی درخواست‌ها.
9. تست امنیتی، دسترس‌پذیری، تست دستگاه واقعی و تهیه نسخه پشتیبان.
